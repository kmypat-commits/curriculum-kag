# Curated research benchmark manifests

This directory contains small, reviewable metric manifests that are safe to
track with the source code. It must never contain model weights, raw EPVO/CEER
records, database dumps, checkpoints, or runtime logs.

The full listwise result is research-only. It is not a production-promotion
record: its Recall@10 remains below the declared acceptance threshold of 0.80.
Runtime outputs continue to live under ignored local directories.
