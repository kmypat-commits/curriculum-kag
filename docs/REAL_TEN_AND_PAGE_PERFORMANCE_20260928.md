## Продолжение диагностики

HTTP через действующий сайт, версия1263, два последовательных запроса на endpoint:
variants 3.056/2.254с, readiness 3.306/0.218с, drafts 0.045/0.028с. Без печати/сохранения токена.
Повторный профиль непосредственного обработчика variants: 0.337с, SQL около0.294с. Первый замер1.753с не является устойчивым CPU временем. Большая разница требует анализа очереди/конкуренции, не обещания ускорения в X раз.

Выявлен конкретный дефект конкурентной обработки: get_variants был async при синхронных ORM-запросах. Регрессия test_variants_nonblocking.py через зарегистрированный HTTP router воспроизвела выполнение запросов в event_loop (RED). Обработчик переведён в обычный def для threadpool FastAPI; ответ не меняется. Полный backend suite запущен; завершение процесса подтвердить отдельно. Live backend ещё не перезапущен: before/after по действующему серверу пока отсутствует.

Три новые программы прошли internal gate, четвёртая генерируется. В культурологии видны профильные курсы, но также смешение психологии/политологии/нескольких методов исследования и бизнес-языка. Это первый сигнал для предметного анализа, не заключение по всем десяти. Нулевые prerequisite_edges сами по себе не означают хорошую педагогическую последовательность.
