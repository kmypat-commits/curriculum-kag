# Состояние constrained reranking: 2026-08-04

## Что проверено

Планировщик сначала формирует широкий фронтир кандидатов, затем применяет ограничения: типовой семестр ЕПВО, уровень образования, пререквизиты, нагрузку 27–33 кредита, покрытие РО и обязательные компоненты ГОСО.

Исправлен матчинг карточек `EPVO-<normalized_id>` с таблицей `epvo_disciplines_normalized`. Ранее часть типовых семестров не находилась из-за сравнения с `approved_course_id`.

## Контрольный результат

После расширения ранжированного фронтира с 50 до 100 кандидатов свежая выборка из 7 программ показала:

| Метрика | Результат |
|---|---:|
| Сырые соответствия семестру, PM1 | 76,82% |
| С учётом пререквизитов | 80,42% |
| С учётом семантических ограничений | 83,49% |
| Программ, прошедших структурный контроль | 6 из 7 |

По отдельным программам результат составил 88,64%, 92,16%, 88,64% и 84,38%; слабые случаи требуют дальнейшей оптимизации распределения кредитов.

Контроль магистерского плана: 120 кредитов, 0 жёстких нарушений, 0 ошибок уровня, 0 неправильных семестров, ГОСО соблюдено. Локальные тесты: 38/38.

## Recall-эксперимент

На независимом clean-v2 split комбинация SBERT + EPVO memory (global weight 0.4, scoped weight 0.4) дала:

- Recall@10: 0,5348 → 0,5657;
- Recall@20: 0,7476 → 0,7580;
- MRR: 0,2898 → 0,3740;
- nDCG@10: 0,3163 → 0,3735.

Модель production не менялась (`production_model_changed=false`). Следующий эксперимент должен подтвердить результат на ещё одном независимом split и только затем рассматривать интеграцию.

Проверка устойчивости при расширении памяти с 64 до 128 кандидатов сохранила те же frozen-test значения и выбранные веса 0,4/0,4. Это означает, что улучшение не связано только с обрезанием пула; production также не менялся.

## Ограничение

Целевой порог 85% пока не достигнут: текущий semantic-adjusted mean равен 83,49%. Основной резерв — глобальная оптимизация обменов дисциплин между семестрами при сохранении ГОСО, кредитов и пререквизитов.
