## Почему локальное удаление трёх связей недостаточно

- 9483 «Английский язык для специальных целей» требует9154 «Техническое
  регулирование в рамках ЕАЭС» и8949 «Биотехнология защиты растений…».
  В глубине цепочки присутствуют почвоведение, семенной контроль,
  экскурсоведение и экология животных.
- 6617 «Электронные образовательные ресурсы» требует8227 «Конфигурированная
  система1С» и8214 «Монтаж и ремонт технологических машин»; глубже находятся
  финансовое моделирование и климатические изменения.
- 5029 «Профессиональный иностранный язык» одновременно требует два B1
  курса3542/3667. Их topics и learning_outcomes совпадают, descriptions
  НЕ полностью совпадают; обе записи описывают первую половину B1.
  Ни один EPVO scope не включает B074/6B073. Это подозрение на альтернативные
  реализации, НЕ автоматически подтверждённая эквивалентность.
- 734/742 (казахский/русский) требуют517 (иностранный язык). Скопированные
  descriptions не доказывают языковую эквивалентность или обязательность
  межъязыковой подготовки. Такие курсы нельзя объединять только по similarity.

До исправления `_assign_epvo_prerequisites` использовал два совпавших токена title,
global domain и ранний semester, выбирая до двух родителей. Этот код не
доказывает происхождение перечисленных старых рёбер: у явно разнопредметных
названий нет требуемого текущим кодом пересечения. Время/автор записи неизвестны.

## Решение, требующее согласования

1. Связи имеют явный provenance/status: подтверждённые hard, предложенные
   advisory, спорные требуют review. Нельзя задним числом объявить все старые
   связи предложенными по одному только отсутствию provenance.
2. Автоматическое сходство даёт предложение, не новый hard prerequisite.
   Утверждение методистом сохраняет основание и scope программы/направления.
3. Существующие цепочки44 курсов проверяются по каждому ребру с исходным
   syllabus, scope и последовательностью. Только предметно отвергнутые связи
   идут в обратимый карантин со snapshot/rollback и журналом причин.
4. Там, где базовый уровень языка реален, сохраняется подготовка. Альтернатива
   между каталоговыми реализациями требует подтверждения уровня/языка/назначения;
   нельзя просто заменить B1 нормативным иностранным языком ГОСО.
5. После TDD исправления источника новых ошибок и согласованного data review:
   отдельный2124, затем весь прежний frozen20 заново. Только после structural,
   hash/identity, required-component и честной content проверки —40offset20.
