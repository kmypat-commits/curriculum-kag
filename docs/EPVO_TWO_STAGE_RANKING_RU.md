# Двухэтапное сопоставление дисциплина–LO

## Схема

1. Классификатор SBERT оценивает вероятность содержательной связи дисциплины с результатом обучения и отсекает слабые пары по порогу, выбранному на validation-наборе.
2. Для прошедших кандидатов отдельный SBERT-ранжировщик вычисляет близость и уточняет порядок дисциплин.
3. Экспериментальный итоговый балл допускает взвешивание классификатора и ранжировщика. Production-вес ранжировщика устанавливается только по validation-набору.
4. Экспертные оценки ЕПВО и обратная связь пользователя сохраняются отдельно и имеют приоритет над прогнозом ИИ.

## Проверенные модели

- лучший классификационный эксперимент: ROC-AUC `0,7748`, F1 `0,7268`;
- лучший отдельный ранжировщик: MRR `0,7933`;
- модели оценивались по образовательным программам, не по случайно перемешанным парам, чтобы избежать утечки данных.

## Безопасность эксплуатации

Ранжировщик выключен по умолчанию (`EPVO_RANKER_ENABLED=false`) и загружается лениво только при явном пересчёте связей. Обычное открытие страниц не загружает модель и не создаёт нагрузку на GPU. При ошибке загрузки система автоматически продолжает работать на прежнем классификаторе/эвристике.

## Решение A/B от 17 июля 2026 года

На 60 validation- и 60 независимых test-программах сравнивались `epvo-sbert-finetuned-40k` и его смесь с `epvo-sbert-mined-triplets-6k`. Validation выбрал вес ранжировщика `0,0`, поэтому двухмодельная смесь не внедрена.

Результат базовой модели при замороженном выборе на test: Recall@5 `0,5187`, Recall@10 `0,6959`, MRR `0,7658`, nDCG@10 `0,6595`. Production-конфигурация сохранена без ухудшения; отрицательный результат оставлен для научной воспроизводимости.
