# Экспертно-взвешенное ранжирование EPVO

Экспертные оценки используются как второй этап после SBERT. Для каждого курса сохраняются тексты результатов обучения из train-программ; связь с оценкой 1 имеет больший вес, чем связь с 0.5, а оценка 0 не используется как положительное evidence. Вес memory выбирается только на validation, затем один раз проверяется на frozen test-разбиении по программам.

Результаты на frozen split:

| Вариант | Recall@10 | MRR | nDCG@10 |
|---|---:|---:|---:|
| Multi-positive SBERT | 0.6734 | 0.7866 | 0.6629 |
| SBERT + expert-weighted memory | 0.6857 | 0.7975 | 0.6789 |

Прирост составляет 1.24, 1.09 и 1.60 процентного пункта соответственно. Это улучшение относится к ранжированию кандидатов и не означает, что модель может самостоятельно заменить академического эксперта. Production-флаг остаётся выключенным до независимой проверки на новых программах.

Артефакт отчёта: `backend/experiment-results/epvo-weighted-memory-benchmark/metrics-archive-weighted-v2.json`.
