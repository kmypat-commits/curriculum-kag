# Анализ покрытия экспертной памяти EPVO — 03.08.2026

На clean-v3 programme-level split проверено пересечение тестовых дисциплин с train по двум ключам:

- нормализованное название: 45,58% тестовых названий;
- стабильный `course_id`: 42,70%;
- объединение двух ключей: около 44,12% уникальных кандидатов.

Следовательно, простое объединение ключей не может приблизить Recall@10 к 90%: больше половины тестовых дисциплин не имеют прямого train-экспертного аналога. Для следующего роста нужны межпрограммные синонимы, направления/группы ЕПВО и дополнительные экспертные связи; использование тестовых связей для обучения было бы утечкой данных.
