# Статус ранжирования дисциплин — 03.08.2026

## Воспроизводимая выборка

Рабочая выборка восстановлена локально из PostgreSQL-слоёв `raw_epvo_*` и таблицы `epvo_discipline_lo_links`. В ней 447 программ, 17 703 экспертные связи и разбиение 303/80/64 (train/validation/test). Пересечение идентификаторов программ между частями отсутствует, ошибочных связей — 0.

Оценочный потолок Recall@10 равен 97,5%, поэтому показатель 90% в принципе достижим. Это не означает, что модель уже достигла 90%: потолок — результат идеального ранжирования.

## Контрольный эксперимент

| Модель | Recall@10 | MRR | nDCG@10 |
|---|---:|---:|---:|
| SBERT 40k + context + lexical rerank | 75,14% | 57,54% | 56,29% |
| Multi-positive pilot (800 groups) + lexical rerank | 76,37% | 60,64% | 58,42% |
| 40k + train-only expert-memory prior | 75,94% | 60,61% | 58,36% |
| SBERT ranking-loss pilot | 76,20% | 59,89% | 58,11% |
| SBERT + прозрачный lexical rerank | 76,42% | 60,30% | 58,42% |
| SBERT 40k + прозрачный lexical rerank | 76,46% | 60,37% | 58,30% |

Вес lexical-компоненты выбирался только на validation. Production-модель не заменялась: прирост пока недостаточен для безопасного внедрения и требует повторной проверки на полном frozen-наборе.

## Следующий эксперимент

Добавить в reranker программный контекст (направление, группу ОП и цель), затем сравнить его на том же test split. После этого — обучить pairwise-модель на экспертных оценках `strength`, сохраняя programme-level split и независимый test.
