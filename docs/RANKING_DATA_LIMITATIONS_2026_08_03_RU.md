# Ограничение экспертной разметки

Проверка PostgreSQL показала: все 932 483 записи `epvo_discipline_lo_links` имеют `strength=1.0` и `expert_level=declared`. Градуированных оценок 0/0,5/1 в исходной выгрузке нет.

Поэтому pairwise-обучение по «силе эксперта» пока невозможно без нового экспертного раунда. Текущие multi-positive эксперименты используют только факт подтверждённой связи и не выдают его за более точную шкалу качества.
