# PydanticAI в Curriculum-KAG

PydanticAI — необязательный слой для структурированных ответов внешней LLM. Он не принимает решения о кредитах, ГОСО, пререквизитах или замене дисциплин. Эти решения остаются за EPVO-доказательствами, правилами планировщика и независимой проверкой.

## Что уже сделано

- Контракты `LocalizedSuggestions` и `AchievabilityReport` проверяют формат ответа.
- Ошибка провайдера или отсутствие пакета безопасно возвращает существующий OpenAI/deterministic fallback вместо HTTP 500.
- По умолчанию `PYDANTIC_AI_ENABLED=false`.
- Изолированная совместимость проверена в `.runtime/pydantic-ai-slim-venv`; production-окружение не меняется.

## Почему не включаем сразу

PydanticAI улучшает типизацию и повторяемость LLM-ответов, но сам по себе не повышает качество выбора дисциплин. Перед включением нужны отдельные тесты задержки, стоимости, отказоустойчивости и сравнение с текущим fallback на одинаковых программах.

## Экспериментальный запуск

```powershell
$env:PYDANTIC_AI_ENABLED="true"
$env:PYDANTIC_AI_MODEL_NAME="openai:gpt-4o-mini"
```

Включать режим следует только при наличии ключа провайдера и после regression-прогона. Любой результат должен пройти общие контракты и планировщик; неподтверждённый текст не становится экспертным доказательством.
