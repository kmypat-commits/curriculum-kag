# Необязательный PydanticAI-слой

Curriculum-KAG уже использует типизированные Pydantic-контракты для ответов
внешнего AI. Они проверяют:

- ровно три цели и от трёх до шести результатов обучения;
- допустимые статусы анализа достижимости;
- оценку от 0 до 100 и покрытие от 0 до 1;
- упоминание выбранных направлений в предложениях.

`backend/app/services/pydantic_ai_adapter.py` содержит необязательный мост к
PydanticAI. По умолчанию он выключен (`PYDANTIC_AI_ENABLED=false`), поэтому
обычный запуск не требует новой зависимости. При включении используются те же
контракты, а ошибка установки, провайдера или модели безопасно возвращает
существующий OpenAI/deterministic fallback.

## Экспериментальное включение

```powershell
pip install pydantic-ai
$env:PYDANTIC_AI_ENABLED="true"
$env:PYDANTIC_AI_MODEL_NAME="openai:gpt-4o-mini"
```

PydanticAI не принимает решения о кредитах, ГОСО, пререквизитах или удалении
дисциплин. Он только структурирует ответ LLM; окончательное решение остаётся
за EPVO-доказательствами, правилами и независимым верификатором.

Совместимость проверена в отдельном окружении:
`pydantic-ai-slim[openai]==2.22.0`. Оно находится в
`.runtime/pydantic-ai-slim-venv` и не входит в production `backend/venv`.
Перед включением в production нужны regression-прогон, проверка таймаутов и
подтверждение сохранения детерминированного fallback.
