# Что означает число дисциплин в интерфейсе

Снимок живой PostgreSQL, 29.09.2026. Запросы были только на чтение в транзакции
`SET TRANSACTION READ ONLY`; таблицы и курсы не изменялись. Числа могут
измениться после импорта или ручного добавления дисциплин.

| Уровень хранения | Число | Значение |
|---|---:|---|
| `raw_epvo_disciplines` | 408 638 | Исходные карточки по программам ЕПВО; один предмет может встречаться многократно. |
| `epvo_disciplines_normalized` | 191 292 | Нормализованные записи; это не окончательные семантические группы эквивалентности. |
| Нормализованные записи с `approved_course_id` | 64 114 | Связи с рабочим каталогом; несколько записей могут указывать на один курс. |
| Различных `approved_course_id` | 50 531 | Рабочие курсы, на которые ссылаются нормализованные записи. |
| `courses` | **51 047** | Все строки рабочего каталога: именно это возвращает `/api/repository/stats` как `total_courses` и показывает интерфейс. |
| `courses` с префиксом `EPVO` | 50 512 | Большая часть рабочего каталога имеет EPVO-код; префикс сам по себе не доказывает предметную уникальность. |
| Различных `lower(trim(title))` в `courses` | 50 883 | Только точное совпадение нормализованного по регистру/краям названия; разные формулировки одного содержания всё ещё считаются разными. |

Разница 51 047 − 50 883 = 164 относится лишь к точным повторениям названия
при такой простой нормализации. **Нельзя вычислять количество содержательно
уникальных дисциплин вычитанием 164**: его ещё нет без проверки описаний,
уровня, языка, тем и контекста программы. Аналогично 50 531 связанных курсов
не равно числу уникальных предметов. Число 51 047 не означает, что каждая
генерация создаёт новый курс: при обычном построении `Course` создаётся лишь
по отдельным путям, например для нормативного компонента или явного переноса
в каталог; причинный прирост требует снимков до/после конкретной операции.

Текущий источник UI: `repository_stats()` в `backend/app/api/repository.py`
считает `count(Course.id)` и кэширует результат; `Repository.jsx` выводит
`repositoryStats.total_courses`. Для интерфейса нужны **разные подписи**:
исходные карточки ЕПВО, нормализованные записи, рабочие курсы, а оценку
содержательно уникальных дисциплин показывать только после отдельной
валидированной группировки с указанной методикой. Переименовать одно число
без определения остальных недостаточно для полноценного каталожного обзора.
