# EPVO expert-memory по стабильному идентификатору — 03.08.2026

В диагностическом benchmark дополнительно проверено сопоставление дисциплин по стабильному `course_id`, а не только по нормализованному названию.

- покрытие memory на тестовых кандидатах: 39,99%;
- Recall@10: 60,86%;
- MRR: 58,27%;
- nDCG@10: 51,98%;
- прирост к прямому SBERT baseline Recall@10: +7,90 п.п.;
- прирост к title-memory clean-v3: +1,66 п.п.

Validation выбрала вес ID=1,0, поэтому объединение с title-memory не дало дополнительного прироста. Это диагностический результат; production-модель не изменялась. Следующий резерв — расширить межпрограммное сопоставление синонимов и экспертных связей, а не просто увеличивать число эпох.
