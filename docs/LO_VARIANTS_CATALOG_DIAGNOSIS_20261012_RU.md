## Приоритеты РО

LOCoverageDashboard.handleSaveWeights отправляет веса в POST /api/projects/lo/weights; endpoint сохраняет LearningOutcome.weight. Старый aggregate_match_scores использует вес для sum/evidence_sum. Но обычная генерация scheduler.build_curriculum_plan направляется в build_verified_joint_schedule → build_joint_frontier, где ranking[cid] — max(match.score, raw), без LearningOutcome.weight. Следовательно, наличие веса в UI/БД не доказывает его влияние на текущий Joint MILP.

Само изменение веса не перестраивает сохранённый план. Усиление приоритета должно проверяться на одинаковых входах по доказанному покрытию конкретного РО; количество дисциплин отдельно не является качеством. Нужны тесты прохождения весов до целевой функции, сохранения структурных ограничений и изменений оценки после ручных правок.

## A/B/C

joint_planner принимает variant_type, но build_joint_frontier вызывается без стратегии варианта; solve_joint минимизирует отрицательную utility с одинаковой целевой функцией. Это не реализует разные цели A/B/C.

planner_build.build_variant запрещает B/C повторить A. Для C дополнительный запрет состава B берётся только из variants.get('B'), то есть из текущего запуска; сохранённый B при отдельной перестройке C здесь не используется. Это возможный путь совпадения B/C. Для установления причины конкретного предупреждения нужны project/version/job id и сохранённые составы; проект не угадывать по прежнему URL.

Требуемая семантика: A — взвешенное покрытие РО; B — минимум новых дисциплин относительно явно зафиксированного исходного плана; C — баланс покрытия и изменений. Не подменять это случайной заменой курса. При отсутствии действительно разных допустимых решений сообщать ограничение, не сохранять дубль как альтернативу. Подтверждённые обязательные компоненты, кредиты, нагрузки, пререквизиты и ГОСО остаются жёсткими.

## Влияние на общую приёмку

Технические 20/20 не являются доказательством работы весов или разных стратегий, а также содержательной пригодности. Содержательная приёмка и переход к 40 остаются открыты.
