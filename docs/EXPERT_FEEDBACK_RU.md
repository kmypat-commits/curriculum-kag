# Экспертная разметка связей дисциплина–РО

В редакторе учебного плана три кнопки теперь сохраняют не только verdict, но и числовую оценку:

- «Подтвердить» — `1.0` (сильная подтверждённая связь);
- «Слабая связь» — `0.5`;
- «Неверная» — `0.0`.

Оценка сохраняется в `match_feedback.corrected_score` вместе со снимком модели и комментарием. Значение ограничено диапазоном 0–1. Эти данные предназначены для следующего pairwise/reranking-обучения и не изменяют текущую production-модель автоматически.
