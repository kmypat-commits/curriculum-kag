# Ручной UI-тест RU/KK/EN

Открыть `http://localhost:3001/` в браузере и повторить каждый пункт для языков `Русский`, `Қазақша`, `English`.

| Экран | Проверка |
|---|---|
| Вход | форма, ошибка авторизации, переключение языка |
| Проекты | список, открытие, удаление, навигация |
| Создание программы | мастер 1–3, области/направления, сохранение |
| Репозиторий | фильтры, описание дисциплины, три языка |
| План | варианты A/B/C, семестры, LO, bridge, переключение языка |
| Покрытие LO | источники покрытия, раскрытие LO, граф |
| Граф | пререквизиты, постреквизиты, компетенции семестра |
| Сравнение ЕПВО | поиск, выбор дисциплин, добавление, уведомление |
| Версии проекта | статус Git, diff, сравнение, новая ветка |
| Силлабус | создание, сохранение, экспорт Word |

Для каждого экрана проверить: нет `�`/mojibake, заголовки и кнопки переведены, нет ошибок в DevTools Console, переходы не возвращают 5xx. Отметить дату, браузер и результат в отчёте приёмки.
