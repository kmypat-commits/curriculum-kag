# Восстановление генерации проекта 852 — 26 октября 2026

## Что показала диагностика

Первый повтор сборки того же проекта завершился примерно за 145 секунд,
статусом `verifier_rejected`. Сборщик нашёл допустимые расписания, но
независимый проверяющий отклонил их из-за отсутствия четырёх обязательных
компетентностных блоков ИКТ: программирование и алгоритмы, данные и базы
данных, системы и сети, информационная безопасность. Финальная проверка не
ослаблялась.

В коде совместного планировщика добавлены ограничения на эти блоки,
построенные из тех же требований и классификатора, что использует независимый
проверяющий. Низкоранговые курсы по обязательным блокам резервируются до
ограничения размера frontier. В fingerprint frontier включён состав этих
ограничений. Добавлены регрессионные проверки на согласованность классификатора
и сохранение курса по информационной безопасности.

Затем GPU-энкодер на RTX 4050 столкнулся с нехваткой памяти во время следующей
попытки. Ранее исключение ошибочно переводило семантический поиск на hash
fallback; это изменяло evidence и приводило к отказу предварительной проверки
по минимальным кредитам EPVO. Теперь ошибки нехватки памяти не превращаются в
успешный hash fallback. Размер CUDA batch ограничен восемью элементами; при
OOM batch уменьшается и повторяется, а неудача после минимального batch
возвращается вызывающему коду. Кэш результата не записывается для неполного
batch.

## Результаты и границы проверки

- 86 тестов ядра совместного планировщика прошли после исправления требований.
- 111 тестов энкодера, scoring и совместного планировщика прошли после
  исправления обработки памяти.
- Прямой dry-run `build_verified_joint_schedule` для project version 852,
  варианта A, прошёл за 3,95 секунды и завершил транзакцию через rollback;
  план в БД этим dry-run не публиковался.
- Рабочая генерация не подтверждена завершённым повтором после последнего
  исправления памяти. Тогда Docker Desktop был остановлен, существующий
  `curriculum-kag-postgres-shadow` завершился; после запуска Docker контейнер
  и backend восстановлены. Повтор из авторизованного интерфейса ещё требуется.
- Локальный frontend доступен на `http://127.0.0.1:3001/`, backend — на
  `http://127.0.0.1:8000/`, PostgreSQL shadow — на `127.0.0.1:5433`.
- Для повтора откройте project 852, выберите только вариант A и запустите
  генерацию один раз. Не создавайте параллельный job. Если он снова завершится
  ошибкой, сохраните job id и stage/traceback из локальных журналов.

Регрессионные логи находятся в `.runtime/ict-core-fix-tests-20261026.log` и
`.runtime/generation-recovery-tests-20261026.log`; runtime-логи не входят в
Git.
