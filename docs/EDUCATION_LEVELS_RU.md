# Уровни и сроки образовательных программ

Справочники и валидация используют коды ЕПВО, соответствующие уровню образования:

- бакалавриат: область/направление `6B…`, группа `B…`;
- магистратура: область/направление `7M…`, группа `M…`;
- докторантура: область/направление `8D…`, группа `D…`.

Продолжительность переводится в семестры по формуле `S = 2Y`, где `Y` — срок в годах. Рекомендуемый объём рассчитывается как `C = 60Y`. Поэтому двухлетняя магистратура создаётся на 4 семестра и 120 кредитов.

Ошибки создания показываются внутри мастера. Backend-список ошибок преобразуется в читаемый текст; всплывающее сообщение `[object Object]` не используется.
