# Статус reranking EPVO — 18.08.2026

## Зафиксированный baseline

Метрики читаются только из независимых benchmark-артефактов, а не из обучающей выборки. Лучший сохранённый вариант по Recall@10 — `epvo-ranking-epvo-sbert-cached-ranker-12k-v2`:

| Эксперимент | Recall@10 | MRR | nDCG@10 |
|---|---:|---:|---:|
| cross-encoder hard-negative pilot | 0.6362 | 0.7323 | 0.6190 |
| ranking benchmark | 0.7041 | 0.7758 | 0.6882 |
| program ranker 8k | 0.7064 | 0.7786 | 0.6904 |
| cached ranker 12k v2 | **0.7066** | 0.7858 | 0.6922 |
| ranking-loss pilot | 0.7071 | 0.7815 | 0.6923 |

Цель Recall@10 ≥ 0,80 пока не достигнута; заявлять 0,90 нельзя. MRR и nDCG улучшаются, но Recall остаётся главным ограничением.

## Следующий воспроизводимый эксперимент

1. Зафиксировать programme-level split и checksum набора.
2. Не смешивать дисциплины одной программы между train/validation/test.
3. Обучить listwise reranker с hard negatives из той же предметной области и уровня образования.
4. Добавить в score отдельные признаки: экспертный балл EPVO, совпадение группы/направления, уровень `6B/7M/8D`, рекомендованный семестр и prerequisite depth.
5. Сравнить Recall@10, MRR, nDCG@10, PR-AUC и устойчивость по программам с baseline; ухудшение не внедрять.

Текущая модель остаётся исследовательским кандидатом. В production-путь допускается только подтверждённый экспертами прогноз с маркировкой «прогноз ИИ».
