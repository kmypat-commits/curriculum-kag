# Сессия и длительная генерация

- Локальная авторизованная сессия действует 8 часов. Этого достаточно для построения бакалаврской программы на 240 кредитов и последующей экспертной проверки.
- Ответ backend `401` не считается ошибкой учебного плана или кредитов.
- При истечении сессии интерфейс сохраняет текущий адрес, открывает страницу входа и после успешной авторизации возвращает пользователя к проекту.
- Страница генерации не показывает `Could not validate credentials` как ошибку алгоритма планирования.
