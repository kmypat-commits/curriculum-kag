# Автоматическая замена bridge-модулей

## Правила отбора

- Кандидат берётся только из нормализованного репозитория ЕПВО.
- Минимальный порог: экспертная оценка ЕПВО не ниже 0,50 или оценка модели не ниже 0,65.
- Одна дисциплина не может заменить несколько bridge-модулей в одном плане.
- Профильный bridge заменяется дисциплиной соответствующего направления.
- Интеграционный bridge междисциплинарной программы заменяется только дисциплиной, метаданные которой подтверждают оба выбранных направления ЕПВО.

## Массовая замена

Кнопка «Заменить все подходящие bridge» выбирает лучший уникальный допустимый кандидат для каждого bridge. Все изменения выполняются одной транзакцией: при ошибке исходный план сохраняется.

После замены система сразу пересчитывает кредиты, покрытие LO, нарушения пререквизитов, нагрузку семестров и показатели качества. Затем пользователь может перегенерировать A/B/C для полного перераспределения дисциплин по семестрам.
