# Репозиторий ЕПВО: индексация и пререквизиты

## Слои данных

`raw EPVO → normalized EPVO → approved repository`.

Кнопка **«Индексировать ЕПВО»** работает только с выбранным направлением или группой ОП: нормализованные записи получают связь с канонической карточкой дисциплины. Исходные raw-записи не изменяются и не смешиваются с рабочим репозиторием.

## Что доступно в карточке

- название и описание на русском, казахском и английском языках;
- пререквизиты и постреквизиты;
- отметка **«Для этой базовой дисциплины пререквизиты не требуются»**. Она очищает входящие пререквизиты и исключает дисциплину из автоматической расстановки.

## Автоматическая расстановка

Автоматическая расстановка учитывает выбранное направление/группу и рекомендуемый семестр: пререквизитом может быть только более ранняя дисциплина из той же выборки. Перед запуском следует отметить фундаментальные дисциплины как не требующие пререквизитов.

## Кредиты при создании ОП

На третьем шаге задаётся целевой объём и технический допуск (по умолчанию `+3` кредита). Генератор стремится к точному объёму; допуск применяется только при невозможности собрать комбинацию дискретных дисциплин точно.
