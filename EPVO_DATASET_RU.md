# Выгрузка открытых данных ЕПВО

## Самый простой запуск без Codex

Дважды щёлкните `download_epvo.bat` в корне проекта. Откроется отдельное окно,
и Python продолжит загрузку без расхода токенов Codex. Окно можно свернуть, но
нельзя закрывать до завершения. После отключения электричества или интернета
запустите файл повторно — готовые карточки будут пропущены.

Текущее количество можно посмотреть двойным щелчком по `epvo_status.bat`.

Сборщик использует только адреса публичной страницы Реестра ОП:
<https://epvo.kz/#/register/education_program>. Он не входит в учётную запись, не
обходит CAPTCHA и не извлекает персональные данные.

## Перед полной выгрузкой

Публичный просмотр не равен разрешению на массовое копирование. Для диссертации
запросите у администратора письменное разрешение, обезличенную выгрузку или
документированные условия API:

- Национальный центр развития высшего образования;
- `cbpiam@n-k.kz`;
- <https://enic-kazakhstan.edu.kz/ru/reestr-op/reestr-op-1>.

## Проба — одна страница

Из папки `backend`:

```powershell
venv\Scripts\python.exe scripts\collect_epvo_dataset.py
```

Результат сохраняется в `experiment-results/epvo-snapshot`: неизменённые ответы
в `raw`, список в `program-list.jsonl`, происхождение и контрольные суммы в
`manifest.json`. При сбое ЕПВО фиктивный пустой датасет не создаётся.
Повторный запуск автоматически продолжает работу после последней сохранённой
страницы. Флаг `--restart` начинает выгрузку списка заново.

## Полный разрешённый снимок

```powershell
venv\Scripts\python.exe scripts\collect_epvo_dataset.py --max-pages 0 --details `
  --permission "письмо администратора №... от ГГГГ-ММ-ДД"
```

Между запросами выдерживается пауза. Официальный экспорт всегда предпочтительнее.
При временном сетевом сбое сборщик выполняет до четырёх попыток с увеличивающейся
паузой, а следующий запуск продолжает с последнего сохранённого файла.

Сырая выгрузка ещё не является готовым ML-датасетом. После получения данных нужно
сопоставить дисциплины, результаты обучения и пререквизиты, проверить дубликаты,
а затем передать нормализованный JSONL в `scripts/prepare_ml_dataset.py`.

Карточки можно докачивать безопасными пакетами; уже сохранённые пропускаются:

```powershell
venv\Scripts\python.exe scripts\collect_epvo_dataset.py --output experiment-results\epvo-full `
  --details-only --details-limit 100
```
## Извлечение экспертных оценок дисциплина–РО

В списке программ оценки не отображаются, но в детальных карточках они находятся в
`disciplinesInfo[].expertCheckResults` и `experts[].expertCheckResult`. Скрипт
`backend/scripts/extract_epvo_expert_labels.py` объединяет обе копии, удаляет повторы
одного эксперта и создаёт `course_lo_pairs.jsonl`. Оценки `0`, `0.5` и `1` сохраняются
как экспертные метки. Разбиение train/validation/test выполняется по целым программам,
чтобы исключить утечку данных между обучением и проверкой.

Обучение локальной контрольной модели выполняется без внешнего ИИ:

```powershell
venv\Scripts\python.exe scripts\train_epvo_expert_baseline.py
```

Состояние извлечения и обучения можно посмотреть двойным щелчком по
`epvo_ai_status.bat` в корне проекта.
