# Curriculum-KAG Generator - Quick Start Guide


> **Актуальный локальный запуск:** дважды щёлкните `start.bat`. Подробности — в `LOCAL_SETUP.md`.

## Быстрый запуск системы

Для обычной локальной работы:

1. Запустите `start.bat`.
2. Дождитесь сообщения о готовности.
3. Работайте по адресу [http://localhost:3001/](http://localhost:3001/).
4. Для остановки запустите `stop.bat`.

Скрипт сам запускает API и интерфейс, а frontend пересобирает только при необходимости.

**Первый вход:**

- Email: `admin@curriculum-kag.local`
- Password: `admin123`

Подготовка нового компьютера и диагностика описаны в `LOCAL_SETUP.md`.

## Базовый сценарий использования

#### Шаг 1: Импорт дисциплин

#### Шаг 1: Импорт дисциплин

1. Перейдите в раздел "Репозиторий"
2. Нажмите "Импорт"
3. Загрузите файл XLSX/CSV с дисциплинами

Формат файла должен содержать колонки:
- `course_id` - уникальный код курса
- `title` - название
- `domain` - домен (D1/D2/general)
- `credits` - кредиты
- `description` - описание (опционально)
- `topics` - темы через | (опционально)
- `learning_outcomes` - результаты обучения через | (опционально)

#### Шаг 2: Создание проекта ОП

1. Перейдите в "Новый проект"
2. Заполните форму:
   - Название программы
   - Два домена (например: "кибербезопасность", "криминалистика")
   - Цель программы
   - Результаты обучения (LO1, LO2, ...)
   - Ограничения (семестры, кредиты)
3. Сохраните проект

#### Шаг 3: Анализ покрытия

1. Откройте созданный проект
2. Нажмите "Вычислить покрытие LO"
3. Система покажет:
   - Топ дисциплины для каждого LO
   - Пробелы в покрытии
   - Предложения по объединению дисциплин

#### Шаг 4: Генерация bridge модулей

1. Если есть пробелы в покрытии LO
2. Нажмите "Сгенерировать bridge модули"
3. Система создаст междисциплинарные курсы

#### Шаг 5: Построение плана

1. Перейдите в "Планировщик"
2. Нажмите "Построить план"
3. Система создаст 3 варианта:
   - **Вариант A**: Максимум покрытия LO
   - **Вариант B**: Минимум новых дисциплин
   - **Вариант C**: Минимум конфликтов
4. Выберите оптимальный вариант

#### Шаг 6: Экспорт

1. Нажмите "Экспорт в XLSX"
2. Получите файл с:
   - Учебным планом по семестрам
   - Матрицей покрытия LO
   - Метриками

## Разработка

### Локальный запуск backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Локальный запуск frontend

```bash
cd frontend
npm install
npm run dev
```

## Структура проекта

```

│   ├── app/
│   │   ├── api/         # REST endpoints

│   │   ├── models/      # Database models
│   │   ├── planner/     # Curriculum planner
│   │   └── services/    # Business logic
│   └── migrations/      # Database migrations
```
