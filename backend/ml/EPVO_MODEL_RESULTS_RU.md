# Результаты моделей связей дисциплина–РО

Данные разделены по целым образовательным программам: одна программа не может
одновременно находиться в train, validation и test. Это исключает завышение качества
из-за утечки одинакового учебного плана.

Лучший безопасный результат без дообучения языковой модели:

- модель: `paraphrase-multilingual-mpnet-base-v2`;
- test ROC-AUC: `0.7031`;
- test PR-AUC: `0.6946`;
- test F1: `0.6886`;
- выборка: 6000 пар из полностью новых программ.

Проверенные альтернативы не превзошли результат:

- локальная нейросеть с нуля: ROC-AUC `0.6825`;
- SBERT с контекстом всей программы: ROC-AUC `0.6911`;
- SBERT и калибратор признаков: ROC-AUC `0.6849`;
- SBERT-голова на явных экспертных отказах: ROC-AUC `0.6832`.

Отсутствующая связь не считается достоверным отрицательным примером: она могла быть
просто не размечена. Отдельный тест на явных экспертных оценках `0` это подтвердил.

Для достижения целевого ROC-AUC `0.80–0.85` требуется дообучение весов SBERT на
контрастивных парах ЕПВО. Замороженные эмбеддинги и поверхностные классификаторы достигли
плато. Дообучение практически требует CUDA-вариант PyTorch и видеокарту.

## CUDA-дообучение

После установки PyTorch CUDA модель была дообучена на RTX 4050:

- 8 000 пар: test ROC-AUC `0.7325`, PR-AUC `0.7278`, F1 `0.7039`;
- 40 000 пар: test ROC-AUC `0.7666`, PR-AUC `0.7681`, F1 `0.7188`;
- recall модели 40k: `0.8450`.

Модель 40k выбрана текущим лучшим артефактом. В приложении её результаты должны
отображаться как **«прогноз ИИ»**, а не как решение эксперта. Порог `0.344931` выбран
только на validation-программах и затем без изменения проверен на test-программах.
